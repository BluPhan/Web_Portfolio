# Web-Portfolio 🌐

A simple, minimalist web portfolio built with HTML, JavaScript, and FantaCSS.

## Tech Stack

- HTML
- JavaScript
- [FantaCSS](https://www.fantacss.smoljames.com) — styling

## Getting Started

This is a static site — no build tools or dependencies required.

### Run locally

Clone the repo:

```bash
git clone https://github.com/BluPhan/Web-Portfolio.git
cd Web-Portfolio
```

Then simply open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```

## Project Structure

```
Web-Portfolio/
├── public/        # Static assets
├── index.html     # Main page
├── styles.css      # Custom styles
└── fanta.css       # FantaCSS framework
```
